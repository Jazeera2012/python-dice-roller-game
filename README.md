# 🎲 Python Dice Roller Game

An interactive Python dice game featuring **ASCII dice visuals**, multiple game modes, random dice rolls, input validation, and score-based challenges.

## ✨ Features

* 🎲 Realistic ASCII-style dice
* 🎮 Multiple game modes
* ⚔️ Player vs Computer battles
* 🎯 Random target challenges
* 🔢 Roll multiple dice at once
* ✅ Input validation
* 📊 Automatic score calculation
* 🔄 Interactive menu system
* 🚪 Easy-to-use exit option

## 🕹️ Game Modes

### 1. 🎲 Simple Dice Roller

Roll any number of dice and see the result using ASCII dice.

The program also calculates the **total value** of all rolled dice.

### 2. ⚔️ Dice Battle

Battle against the computer!

Both the player and computer roll the same number of dice. Their totals are compared to determine the winner.

Possible results:

* 🏆 You Win
* 💻 Computer Wins
* 🤝 Draw

### 3. 🎯 Target Number

The game generates a random target number based on the number of dice.

Your goal is to roll the dice and get as close to the target as possible.

Results include:

* 🎉 Perfect hit
* 🔥 Very close
* ❌ Missed target

## 🎨 ASCII Dice

Instead of displaying only numbers, the game uses custom ASCII dice:

```text
┌─────────────┐
│  ●       ●  │
│             │
│      ●      │
│             │
│  ●       ●  │
└─────────────┘
```

This makes the terminal output more visual and interactive.
